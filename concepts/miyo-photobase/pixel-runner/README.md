# Miyo Photobase

A photo-inspired tuxedo-cat runner drawn as pixel art. This pack contains only the sprite art, no source photographs.

- 28 distinct right-facing poses at 67 × 36 px.
- Transparent hard-alpha PNGs. GIF: 20 ms/frame, 560 ms per loop.
