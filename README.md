# runcat more runner

Pixel-art runner animation concepts.

## Structure

- `concepts/<character>/<variant>/frames/`: native PNG animation frames
- `concepts/<character>/<variant>/previews/`: GIF previews
- `concepts/<character>/<variant>/docs/`: contact sheets and notes

## Concepts

- `concepts/runcat/head-locked-chase/`: 8-frame black cat run, head-height locked, with a subtle 1px camera-chase offset.
- `concepts/white-dog/head-locked-chase/`: 8-frame white dog run based on a supplied puppy reference, head-height locked, with a subtle 1px camera-chase offset.
- `concepts/squirrel/head-locked-chase/`: 8-frame squirrel run based on a supplied squirrel reference, single-scale fitted, with a subtle 1px camera-chase offset.
